## 🌟 Features

- Modern, responsive design with React and Tailwind CSS
- Interactive 3D graphics using Three.js and Spline
- Animated UI with Framer Motion and GSAP
- Project gallery with detailed modals and tech stack icons
- Contact form with EmailJS integration
- Custom cursor, floating robot, and animated backgrounds

## 🛠️ Tech Stack

- **Frontend:** React, Vite, Tailwind CSS, Framer Motion, GSAP
- **3D & Animation:** Three.js, @react-three/fiber, Spline
- **UI/UX:** Custom SVGs, responsive layouts, modern design
- **Other:** EmailJS, React Icons, Parallax Tilt, and more

## 📂 Project Structure

- `src/components/` – Main UI components (About, Projects, Skills, etc.)
- `src/assets/` – Images, 3D models, and SVGs
- `src/contexts/` – Theme and global context
- `public/` – Static files and assets
